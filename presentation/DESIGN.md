## 시각 축 (thesis)

이 연구의 핵심 주장은 **LLM이 생성하는 것 / 결정론적 코드가 판정하는 것의 경계**다.
그래서 그 경계 자체가 슬라이드의 시각적 척추다.

- **앰버** = LLM이 생성 (확률적 · 재시도 가능)
- **틸** = 결정론적 코드가 판정 (재현 가능 · 해시 감사)

모든 구조 슬라이드는 이 선을 따라 좌(앰버) / 우(틸)로 갈린다.

## 슬라이드 순서 (13매)

두 참고 자료가 공통으로 쓰는 흐름(동기 → 관련연구 → 전체구조 → 모듈 → 실험 → 한계·결론)을
따르되, 우리 축인 **검증 경계**를 5번에 두어 이후 모든 슬라이드가 그 그림을 참조하게 한다.

| # | 제목 | 역할 |
|---|---|---|
| 1 | 표지 | 제목 · 부제 · 근거 스탬프 |
| 2 | 동기 | 운용자 부담 + "LLM 출력을 무엇으로 믿는가" 두 질문 |
| 3 | 관련 연구 대비 | MP4MR / LSMP / 본 연구 — 우열이 아니라 검증 축의 차이 |
| 4 | 전체 구조 | 파이프라인 한 줄 + 5계층 스택 |
| 5 | **검증 경계 (핵심)** | LLM이 생성 / 결정론적 코드가 판정 |
| 6 | 계층 1·2 — RQ1·RQ2 | 자연어 → Validator → CBBA → 2D 실행 |
| 7 | 계층 3 — RQ3 | 실행 전 다중 턴 대화, fail-closed grounding, MissionPatch |
| 8 | 계층 4 — RQ4 | checkpoint 선택적 재할당 (bidder-connected selective release) |
| 9 | 계층 5 — RQ5 | 상황 대응 정책의 counterfactual |
| 10 | 실측 결과 | 계층별 원시 수치 (소표본 명시) |
| 11 | 재현성 · 감사 | event stream + 4종 hash + LLM 호출 전 커밋한 gold |
| 12 | 주장하지 않는 것 | 자동 인식 아님 · telemetry 아님 · 우열 주장 안 함 · 소표본 |
| 13 | 결론 · 후속 | 자연어가 전 주기 인터페이스 / 후속: platform 통합, recheck 어휘, 다중 scene |
